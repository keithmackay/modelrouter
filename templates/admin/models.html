Providers

Disabling a provider takes every model behind it out of rotation immediately — routing, load-balancer pools, alias targets and /v1/models. A direct request for a disabled model returns 403 naming the reason. Unlike a circuit-breaker trip this is sticky: it never auto-recovers and survives a restart, so it stays in force until someone re-enables it here.

Model Aliases

Runtime aliases let callers request an abstract name (e.g. deep) instead of a concrete model. Changes take effect on the next request — no restart. Precedence: aliases defined here override the Alias column on registered models, which override routing.model_aliases in config.toml. Every change is written to the audit log.
